LOG HOME — WEB EDITION
======================

이 폴더는 웹브라우저에서 사용하는 Log Home 배포본입니다.
프로그램 설치나 별도 서버가 필요하지 않습니다.
압축을 푼 뒤 index.html을 직접 열거나 GitHub Pages에 올려 사용할 수 있습니다.

기본 상태창 템플릿
- '자동 Props · Black'과 '자동 Props · White'가 삭제되지 않는 기본 템플릿으로 포함되어 있습니다.
- 로그 본문에 등록된 JSX 컴포넌트 이름과 Props를 자동으로 찾아 신문형 다단 레이아웃에 배치합니다.
- Props 이름이 미리 템플릿 코드에 등록되어 있지 않아도 JSX 태그에 들어 있는 값을 읽습니다.
- 템플릿 화면은 '기본'과 '사용자 커스텀'으로 나뉩니다. 두 카테고리는 처음에는 접혀 있으며 제목을 누르면 열리고 다시 누르면 접힙니다. 기본 템플릿 미리보기의 이름, 장소, 감정 등은 디자인 확인용 예시이며 실제 로그에서는 인식된 Props로 교체됩니다.

화면 보기
- ARCHIVE의 보기 아이콘에서 카드 보기와 리스트 보기를 바꿀 수 있으며 선택은 데이터 파일 설정에 저장됩니다.
- 로그가 많아지면 하단 화살표로 페이지를 넘길 수 있고 10개, 30개, 50개씩 보기를 선택할 수 있습니다.
- 홈의 전체 로그, 즐겨찾기, 캐릭터/페어, 템플릿 수는 앞에 0을 붙이지 않은 일반 숫자로 표시됩니다.
- 데이터 파일 연결을 마치고 메인 화면에 처음 들어오면 중요한 주의사항이 자동으로 한 번 표시됩니다. 이후에는 자동으로 다시 표시되지 않으며 왼쪽 아래의 작은 ! 버튼으로 필요할 때 다시 확인할 수 있습니다.
- favicon.svg는 브라우저 탭에 표시되는 Log Home 아이콘입니다.

로그 등록
- 일반 글과 함께 div, span, br 등의 본문 HTML을 직접 등록할 수 있습니다.
- 본문 HTML의 script, onload/onclick 같은 실행형 코드는 안전을 위해 제거되며, JSX 상태창은 본문과 분리된 제한 영역에서 실행됩니다.
- 따옴표 안과 괄호 (...) 안의 문장에 서로 다른 강조 색을 선택할 수 있습니다.
- 상태창 템플릿을 선택하면 등록·수정창 안에서 JSX 상태창이 바로 표시되고, 본문 Props를 바꿀 때마다 즉시 갱신됩니다.
- '전체 미리보기' 버튼을 누르면 이미지 편집기와 별개인 로그 미리보기 창에서 현재 본문 글꼴, 따옴표·괄호 강조 색, 상태창을 함께 확인할 수 있습니다.
- 로그마다 본문 글꼴을 선택할 수 있으며 해당 설정은 그 로그에만 저장되고 다른 로그나 새 로그의 글꼴을 바꾸지 않습니다. 글꼴 선택 목록의 이름도 가능한 경우 해당 글꼴 모양으로 표시됩니다.
- 리디바탕과 부크크 명조를 포함해 본문용 글꼴을 선택할 수 있습니다.
- 바뚜보루희망체 선택지는 이름만 표시하며, 재배포 조건 때문에 폰트 파일은 이 폴더에 포함되지 않습니다.
- 저장된 로그를 수정한 뒤 저장하면 홈으로 이동하지 않고 수정된 로그 상세 화면을 다시 보여줍니다.

개인 데이터 저장
- 웹사이트에는 Log Home 코드만 있습니다.
- 로그, 카테고리, 캐릭터/페어, JSX 템플릿, 설정, 작성 중 초안은 사용자가 선택한 실제 JSON 파일에 저장됩니다.
- 기본 파일명은 loghome-data.json이며 저장 위치는 사용자가 직접 선택합니다.
- 기본 저장 기능은 이 데이터 파일을 GitHub에 업로드하지 않습니다.
- 브라우저를 완전히 닫은 뒤 다시 열면 보안 정책상 파일 접근 권한을 다시 허용해야 할 수 있습니다. 브라우저가 이전 파일 핸들을 기억하고 있으면 파일을 다시 찾지 않고 '이전에 연결한 파일 다시 허용'을 누를 수 있습니다.
- 브라우저 권한 기록이 사라져도 실제 JSON 파일은 PC에 남습니다. 같은 파일을 '기존 데이터 파일 열기'로 다시 선택하면 됩니다.

처음 접속할 때
- 새 데이터 파일 만들기: 처음 사용하는 사람이 새 loghome-data.json을 생성합니다.
- 기존 데이터 파일 열기: 이미 사용하던 loghome-data.json을 연결합니다.
- 이전에 연결한 파일 다시 허용: 해당 웹주소에서 파일 핸들을 기억하고 있지만 권한만 만료된 경우 표시됩니다.

백업 / 복원
- BACKUP 메뉴에서 '백업 파일 저장'을 누르면 현재 데이터의 별도 JSON 복사본을 만듭니다.
- '백업에서 복원'을 사용하면 선택한 백업 내용으로 현재 연결된 데이터 파일 내용을 교체합니다.
- 원본 데이터 파일과 백업 파일은 모두 사용자 PC에 저장됩니다.

로그 이미지 저장
- 저장된 로그를 연 뒤 '이미지 저장'을 누르면 이미지 편집창이 열립니다.
- 미리보기 안을 위·아래와 좌·우로 스크롤할 수 있습니다.
- 분할 저장을 선택하면 미리보기 상단의 ← → 버튼으로 분할선 사이의 실제 잘린 페이지를 한 장씩 옆으로 넘겨 확인할 수 있습니다. '분할선 편집'을 누르면 전체 화면으로 돌아갑니다.
- − ＋ FIT 버튼으로 확대·축소하거나 화면에 맞출 수 있고, 가운데 숫자 칸에 25~160 사이의 확대 비율을 직접 입력할 수도 있습니다.
- 제목, 파일명, PNG/JPEG 형식, 가로 크기, 밝은/어두운 배경, 본문 글자 크기, 글꼴, 색상, 여백을 조정하고 바로 미리볼 수 있습니다. 배경·글자·강조 색을 바꿔도 보고 있던 스크롤 위치가 유지됩니다. 따옴표와 괄호 강조 색은 각각 따로 지정할 수 있습니다.
- 시스템 글꼴 외에 Pretendard, 나눔명조, 조선일보명조, 리디바탕, 부크크 명조, 바뚜보루희망체, 고운돋움, IBM Plex Sans KR, 명조·세리프를 선택할 수 있습니다. 웹 글꼴을 처음 불러올 때는 인터넷 연결이 필요하며, 불러오지 못하면 비슷한 기본 글꼴로 표시됩니다.
- 저장 이미지에는 JSX 상태창 화면을 넣지 않고, 선택한 Props만 본문 아래에 props=내용 형식의 일반 텍스트로 기록할 수 있습니다.
- 편집창에서 Props 줄글 표시 여부를 켜고 끌 수 있고, 이미지에 넣을 Props만 고르거나 ↑ ↓ 버튼 또는 끌기로 순서를 바꿀 수 있습니다.
- 긴 로그는 한 장 또는 직접 지정한 장수로 저장할 수 있습니다. 처음 분할선은 균등하게 배치되며, 선을 한 번 누른 뒤 미리보기를 스크롤하거나 화면 안에서 마우스를 위아래로 움직이면 선이 따라옵니다. 같은 선을 다시 누르면 현재 위치에 고정됩니다.
- 자주 쓰는 글꼴·색상·여백 조합은 이름을 붙여 프리셋으로 저장할 수 있습니다. 프리셋은 현재 연결된 loghome-data.json의 설정에 보관됩니다.
- 여러 로그를 카테고리별로 살펴보고 골라 한 번에 저장할 수 있습니다. 이미지가 여러 장이면 ZIP 한 개 또는 각각의 파일 중 저장 방식을 한 번 선택합니다.
- 완성된 이미지와 ZIP은 서버나 데이터 JSON에 업로드되지 않고 사용자가 선택한 PC 위치에 별도 저장됩니다.

브라우저
- PC 로컬 파일 직접 저장에는 File System Access API가 필요합니다. 최신 Chrome, Edge, Whale 등 Chromium 계열 데스크톱 브라우저를 권장합니다.
- 지원하지 않는 브라우저에서는 몰래 localStorage로 대체 저장하지 않습니다.

주의
- 실제 loghome-data.json을 삭제/손상/덮어쓰거나 저장 드라이브를 초기화하면 데이터가 사라질 수 있습니다.
- 같은 데이터 파일을 여러 탭/창에서 동시에 편집하면 마지막 저장이 앞선 변경을 덮어쓸 수 있으므로 한 번에 한 창에서 사용하는 것을 권장합니다.
- JSX 템플릿은 실제 JavaScript로 실행됩니다. 신뢰할 수 있는 코드만 등록하세요.
