Log Home의 화면과 기능은 웹에서 열리지만, 개인 로그는 사용자가 직접 선택한 loghome-data.json 파일에 저장됩니다. 웹사이트를 업데이트해도 이 파일은 그대로 유지됩니다.

01 · 어디에 저장되나요?

로그, 카테고리, 캐릭터 / 페어, 템플릿과 설정은 선택한 JSON 파일 안에 저장됩니다. 저장 위치는 사용자가 직접 정합니다.

02 · 왜 권한이 필요한가요?

웹페이지가 PC 파일을 마음대로 수정하지 못하도록 브라우저가 접근을 확인합니다. 브라우저를 다시 켰을 때 권한을 한 번 더 허용해야 할 수 있습니다.

03 · 웹 업데이트와 데이터

GitHub Pages의 Log Home 코드만 새 버전으로 바뀝니다. 기본 저장 기능은 개인 데이터 파일을 GitHub에 업로드하지 않습니다.

이 브라우저에서는 PC 파일 직접 저장 기능을 사용할 수 없습니다.
Log Home의 로컬 파일 저장은 File System Access API를 지원하는 최신 Chrome, Edge, Whale 등 Chromium 계열 데스크톱 브라우저가 필요합니다.
파일 권한 기록이 지워지거나 브라우저를 바꿔도 실제 loghome-data.json은 PC에 남습니다. 이 경우 기존 데이터 파일 열기에서 같은 파일을 다시 선택하면 됩니다.
